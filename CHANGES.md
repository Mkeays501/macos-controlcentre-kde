# Changes and Attribution

## Version 1.0.0 — November 2, 2026

This project is a modified derivative of [Control Centre for KDE](https://github.com/Prayag2/kde_controlcentre), originally developed by Prayag Jain (Prayag2).

### Modifications

- Introduced a macOS-inspired Control Centre interface with revised visual styling.
- Adjusted widget dimensions, spacing and text alignment.
- Modified the expanded Control Centre layout and component arrangement.
- Applied KDE Plasma 6 compatibility adjustments, including removal of the problematic Night Light component.
- Assigned the independent plugin identifier `com.github.mkeays501.macoscontrolcentre`.
- Updated widget metadata and project attribution.
